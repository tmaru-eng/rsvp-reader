# ことば送り — 日本語 RSVP リーダー

TXT・テキスト入りPDF・EPUBを、画面中央に文節ごとに表示して読む静的Webアプリです。ファイルと本文はブラウザ内で処理し、外部へ送信しません。

## 使い方

1. TXT、PDF、EPUBを選ぶか、文章を貼り付けます。ファイルはドロップしても読み込めます。
2. 「再生」を押します。画面中央のタップでも再生・停止できます。
3. 速度、文節をまとめる数、最小字数、文字サイズ、句読点の間、注視点ガイドを調整します。
4. 「本を選ぶ」から最近読んだ本を選ぶと、保存した位置から再開します。

### 操作

- `Space`: 再生・停止
- `←` / `→`: 1チャンク移動
- `Shift` + `←` / `→`: 前後の段落へ移動
- `↑` / `↓`: 速度を毎分50字ずつ変更
- スマートフォン: 中央をタップして再生・停止、左右スワイプで移動

## 対応ファイル

- **TXT / 貼り付け:** UTF-8を厳密に読み、失敗したらShift_JISとして読みます。青空文庫のルビ・注記・記号説明・底本情報を除き、最初の2行を作品名・著者として扱います。
- **PDF:** PDF内にテキストがあるものに対応します。日本語CMapをアプリに同梱します。スキャン画像のOCRには対応しません。縦書きPDFは抽出順が崩れる可能性を警告します。
- **EPUB:** JSZipでコンテナ、OPF、spine順のXHTMLを読みます。ルビの読みと補助記号を除き、見出しと本文を保持します。DRM付きEPUBは読み込めません。

## 開発

Node.js 20.19以上とnpmを使います。

```sh
npm install
npm run dev
```

テストと本番ビルド:

```sh
npm test
npm run build
npm run preview
```

Vitestは青空文庫のShift_JIS実ファイル、ルビ付きEPUB、日本語PDFを使って、各形式の抽出、チャンク化、表示時間、設定としおり保存を検証します。

## GitHub Pages向けビルド

Pagesではリポジトリ名をbase pathに指定してビルドします。`<repo-name>` は公開先の実際のリポジトリ名に置き換えてください。

```sh
VITE_BASE_PATH=/<repo-name>/ npm run build
```

生成物は `dist/` です。ユーザーサイトのルート (`https://<user>.github.io/`) に配置する場合は `VITE_BASE_PATH=/` を指定します。PDF workerと日本語CMapのURLにもこのbase pathが反映されます。

このリポジトリではアプリをローカルに実装・検証しています。GitHubへの作成、push、公開は行いません。

## 保存とプライバシー

読み込んだ本文と読書位置はIndexedDB、設定はlocalStorageに保存します。作品本文のSHA-256を本のIDに使います。データはこのブラウザのプロファイル内に残り、同じブラウザで再訪したときにしおりを再開できます。ブラウザのサイトデータを消去すると保存内容も消えます。

## 既知の制限

- BudouXは文節境界を推定するため、すべての作品で自然な区切りになるとは限りません。「まとめる」と「最小字数」で調整できます。
- 縦書きPDFの抽出順は警告のみで、読み順を自動修復しません。画像PDFのOCRもありません。
- 画面消灯防止はWake Lock対応ブラウザで再生中にだけ有効です。
