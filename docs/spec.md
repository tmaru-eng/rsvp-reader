# RSVP Reader 仕様（MVP）

作成: 2026-09-27。参考: 花笠さんの投稿 https://x.com/hanagasa_ai/status/2103523505598075353 （「蜘蛛の糸」の RSVP サンプル動画）

## 目的
日本語の本（テキスト / PDF / EPUB）を読み込み、画面中央に文節ごとに高速表示して読む（RSVP: Rapid Serial Visual Presentation）。PC とスマホの両方のブラウザで使う。

## 形態
- サーバー不要の静的 Web アプリ。ファイルはブラウザ内だけで処理し、外部に送らない。
- 技術：Vite + TypeScript（フレームワークなし、または軽量なもの）、BudouX（文節分割）、pdfjs-dist、JSZip、vitest。
- 公開は GitHub Pages を想定（repo 作成・公開はユーザー承認後）。開発中は `npm run dev` の localhost。

## 画面（参考画像 `reference-screenshot.png` に準拠）
- 上部：書名・著者、キー操作の案内。
- 中央：現在のチャンクを大きく表示。上下に赤い注視点ガイド（縦線）。
- 下部：進捗バー、`現在字数 / 総字数`、`残り 約m:ss`。
- 操作行：先頭へ、再生/停止、速度スライダー（字/分、既定 600、範囲 200〜3000）、まとめる（1/2/3 文節ずつ）、最小字数（なし/2/3/4 字以上）、文字サイズ、句読点で間をとる（チェック）、注視点ガイド（チェック）。
- 最初の画面：ファイル選択（ドラッグ&ドロップ可）とテキスト貼り付け欄、最近読んだ本の一覧（しおりから再開）。

## 入力
### テキスト（.txt / 貼り付け）
- 文字コード自動判定：まず UTF-8（fatal）で読み、失敗したら `TextDecoder('shift_jis')`。
- 青空文庫記法の除去：ルビ `《…》`、ルビ開始 `｜`、注記 `［＃…］`、冒頭の説明ブロック（`-------` で囲まれた記号説明）、末尾の底本情報（`底本：` 以降）。
- 冒頭 1〜2 行を書名・著者として採用（青空文庫形式の場合）。

### PDF
- pdfjs-dist。日本語用に CMap を配布（`pdfjs-dist/cmaps` を public にコピー、`cMapUrl` + `cMapPacked: true`）。worker は Vite の `?url` import で指定。
- テキスト項目の連結は、日本語同士の間に空白を入れない。段落区切りは行間（y 座標の差）で判定。
- テキストが取れない（スキャン画像）PDF は「OCR 非対応」と表示して終了。
- 縦書き PDF は抽出順が崩れる可能性がある。MVP では検出して警告を出すところまで。

### EPUB
- JSZip → `META-INF/container.xml` → OPF → spine 順に XHTML を読み、本文テキストを抽出。
- `<rt>` `<rp>` を除去（ルビ）。見出しは章区切りとして保持。
- DRM 付き（`META-INF/encryption.xml` あり）は「読めません」と表示。

## 本文の処理
1. 正規化：改行を段落区切りとして保持、連続空白の整理。
2. 文節分割：BudouX（ja モデル）で段落ごとに分割。
3. チャンク化：「まとめる」数ぶん文節を結合。「最小 N 字」未満のチャンクは次とつなぐ（段落末は前とつなぐ）。句読点・閉じ括弧で始まるチャンクは作らない。
4. 各チャンクは `{text, charStart, paragraphIndex, endsWithPunct}` を持つ。

## タイミング
- 表示時間 = max(下限 120ms, 字数 ÷ 速度(字/分) × 60000) × 倍率。
- 倍率：`、` で 1.5、`。！？」` で 2.0、段落末で 2.5（「句読点で間」がオフなら 1.0）。
- タイマーは `setTimeout` を `performance.now()` 基準で補正し、累積のずれを出さない。
- 残り時間は残りチャンクの表示時間の合計から計算。

## 操作
- PC：Space 再生/停止、←→ 1 チャンク、Shift+←→ 段落、↑↓ 速度 ±50、V（第 2 弾の縦表示用に予約）。
- スマホ：画面中央タップで再生/停止、左右スワイプで 1 チャンク移動、下部 UI はタッチしやすい大きさ。
- 再生中は Screen Wake Lock を取得（非対応ブラウザでは無視）。

## 保存
- IndexedDB：本ごとに `{id: 本文の SHA-256, title, author, 位置(チャンク番号), 最終閲覧日時}`。本文も保存して再開時に再読込不要にする。
- 設定（速度・まとめる・最小字数・文字サイズ等）は localStorage。

## 第 2 弾以降（MVP 外）
人名の色分け、人物ラベル（章の最初 3 回）、人名で少し長く表示、縦表示、URL から本文取得、スキャン PDF の OCR。

## 完了条件
- vitest：青空文庫パーサ（SJIS 判定・ルビ/注記/底本除去）、チャンク分割（まとめる・最小字数・句読点の扱い）、タイミング計算。
- 実物で確認：青空文庫の SJIS の txt（例：蜘蛛の糸）、日本語のテキスト入り PDF、ルビ付き EPUB を読み込み、表示・速度変更・しおり再開ができる。
- スマホ幅（390px）でレイアウトが崩れない。
