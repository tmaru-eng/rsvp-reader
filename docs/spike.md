## a. BudouX と青空文庫「蜘蛛の糸」

- `budoux` 0.7.0 の `loadDefaultJapaneseParser()` を使い、青空文庫の配布 ZIP（`https://www.aozora.gr.jp/cards/000879/files/92_ruby_164.zip`）に含まれる `kumono_ito.txt` を取得した。
- Shift_JIS として復号でき、元ファイルは8,250 bytes、復号後は4,346文字。ファイルは [kumo-no-ito-sjis.txt](../test/fixtures/kumo-no-ito-sjis.txt) に置いた。

**依存バージョン:** npmのBudouX 0.8〜0.9配布メタデータにはGoogle Artifact Registry認証パッケージが含まれ、`uuid`の中程度の監査警告が発生した。公式 `v0.7.0` のマニフェストにはその依存がなく、日本語分割結果も同じ用途に十分だったため、実装では `budoux@0.7.0` に固定した（[公式マニフェスト](https://raw.githubusercontent.com/google/budoux/v0.7.0/javascript/package.json)）。

## b. pdfjs-dist と日本語 CMap

- `cupsfilter` で日本語を含む1ページPDFを自前生成した。PDF内には `HiraginoSans-W3` の CID Type 0 フォントがあり、`pdftotext` で日本語本文を取得できた。生成物は [japanese-text.pdf](../test/fixtures/japanese-text.pdf)。
- `pdfjs-dist` 6.3.289 の `getDocument()` をVite配信ページのブラウザで実行し、`cMapUrl: "<base>/cmaps/"`, `cMapPacked: true` を指定したところ、次を抽出できた。

```text
日本語PDF抽出テスト
蜘蛛の糸は、極楽の蓮池から地獄へ垂れています。
芥川龍之介の作品です。
```

- `pdfjs-dist/cmaps` の169ファイル（約1.6 MB）を `public/cmaps/` にコピーすれば、ViteからHTTP配信してブラウザで読める。Viteの `base` をCMap URLにも反映する。
- Node環境から `cMapUrl` に `file://` またはHTTP URLを渡す試行ではPDF.jsのNode用CMapリーダーが失敗した。NodeテストではCMapディレクトリの通常のファイルシステムパスを渡し、ブラウザでは `BASE_URL` から組み立てたHTTP URLを使う。ブラウザでのHTTP配信を実際に確認できたため、仕様のブラウザ構成を採用し、設計変更は不要。
